# Bank-of-America-Consumers_Complaints-and-Finalcial-Service-Analysis
To analyse complaint trends, frequently reported issues, financial products associated with complaints, recorded company responses and complaint-processing timelines.

### Objectives 

1. Investigate which Financial Products and Issues are mostly complained about

2. Investigate the complaints forwarding timeline 

3. Evaluate Company's response 

4. Analzye complaints Trend 

5. Validate data 


### Dataset Overview

Company ; Bank of America

Agent :  CFPB

Complaints :62,516

Financial Products : 9

Issues:76

Year : 2017 to 2023



### Tools

1. Excel 

Power Query - Data cleaning 

Pivot table - Evaluate categorical data 

2. Power BI - Visualization 

Power Query - Data Filling 

3. SQL - Data Validation
